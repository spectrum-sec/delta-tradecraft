# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

This file is a pointer, and deliberately does not paraphrase or reconstruct the text: a
reconstructed code of conduct is not a code of conduct. Read it at the canonical URL above.

**Enforcement contact: report privately to the repository maintainers.** Use GitHub's private
vulnerability reporting on this repository, under the Security tab, and mark the report as a conduct
matter rather than a security one. It is the only private channel this project currently operates,
and routing conduct reports through it is deliberate: a conduct report should never have to be filed
in public to reach someone.

Maintainers: if this project later publishes a monitored address, replace this paragraph with it. An
address is better than a form, because a person can be replied to.

## Two notes specific to this project

Neither replaces the Covenant. Both name behaviors this project will see more of than most.

1. **Technical disagreement is the work, not an attack.** "This `detectable` verdict is wrong, and
   here is the vendor document that refutes it" is the most valuable thing you can say here. Say it
   about the object, with the source attached.
2. **Do not rewrite a contributor's reasoning to match your own.** If you disagree with an object,
   argue it in review or open a competing one. Silently averaging two analyses produces a third that
   inherits both failure modes and neither's guarantees, and it teaches the author that authorship
   here is provisional.
